# Autonomous-Agent-New-Hire-Onboarding-

This is a project built using the Microsoft Power Platform to demonstrate how automation can enhance the new employee onboarding experience — specifically through onboarding buddy  assignment.

📌 Project Overview

The goal of this project is to simulate an onboarding workflow that:
- Automatically assigns a buddy to new hires
- Sends a personalized welcome email
- Updates the new hire's record in real time

Built using Power Automate and Dataverse, this low-code solution is designed to streamline repetitive HR tasks while improving the employee experience.


 ⚙ How It Works

1. Dataverse Tables  
   - Two custom tables were created in Dataverse:
     - New Employees
     - Onboarding Team

2. Trigger
   - The workflow is triggered automatically when a new record is added to the New Employees table.

3. Buddy Assignment
   - The flow selects a buddy from the Onboarding Team table.

4. Email Notification
   - A personalized welcome email is sent to the new hire, introducing them to their assigned buddy.

5. Status Update
   - The employee record is updated to reflect:
     - Buddy Assigned = Yes
     - Welcome Mail Sent = Yes


🚀 Highlights

- ✅ Built entirely with *Power Automate* using natural language and low-code logic
- ✅ No coding experience required
